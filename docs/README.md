## Machine-readable evidence

These committed artifacts support review and automated checks. The Python pin in
[parity-inventory.json](parity-inventory.json) records a historical compatibility baseline;
Blackbox TypeScript is canonical. Run commands from the repository root. Follow the
[pin update procedure](PARITY_MAINTENANCE.md#bumping-the-recorded-pin) when changing that baseline.

| Artifact                                                 | Provenance and checks                                                                                                                                                                                                                                                                     |
| -------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [parity-inventory.json](parity-inventory.json)           | TypeScript feature statuses, separate Python dispositions and pin, normalized with evidence from `scripts/lib/parity-evidence.mjs` by `pnpm generate:parity:inventory`; checked by `pnpm check:parity`.                                                                                   |
| [parent-baseline.json](parent-baseline.json)             | Pinned Python tree, catalog requirement names/statuses, evidence files and test modules, generated by `pnpm parity:update-parent-baseline -- --parent <checkout>`; consistency checked offline by `pnpm check:parity`, checkout freshness by `pnpm parity:python -- --parent <checkout>`. |
| [parity-test-crosswalk.json](parity-test-crosswalk.json) | Enumerates executable TypeScript tests first, with explicit Python mappings/N/A reasons and all frozen Python module dispositions; divergence notes in `scripts/generate-test-crosswalk.mjs`; generated by `pnpm generate:parity:crosswalk` and checked by `pnpm check:parity`.           |
| [catalog-snapshot.json](catalog-snapshot.json)           | Built bundled model and pricing catalogs stamped with the inventory pin; generated by `pnpm generate:catalog` and checked by `pnpm test:package`.                                                                                                                                         |
| [public-api.json](public-api.json)                       | Package export paths and root symbol names from `package.json` and `src/index.ts`; generated by `pnpm generate:api` and checked by `pnpm check:api`.                                                                                                                                      |

The Markdown [parity matrix](PARITY_MATRIX.md) is generated from the inventory by
`pnpm generate:parity:matrix` and checked by `pnpm check:parity`. Canonical native expectations live under
[tests/fixtures/typescript](../tests/fixtures/typescript/); frozen compatibility samples live
under [tests/fixtures/python](../tests/fixtures/python/), with replay suites under
[tests/compatibility](../tests/compatibility/). Their generation and checks are
covered in [parity maintenance](PARITY_MAINTENANCE.md). Update generated artifacts through
their scripts. Command definitions live in [package.json](../package.json).
